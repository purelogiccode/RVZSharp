# RVZSharp API Reference

RVZSharp is a pure managed .NET library for reading and writing Dolphin RVZ/WIA disc images
and decoding the legacy GameCube/Wii formats (GCZ, CISO/WBI, WBFS, TGC, NFS).

This site is generated by [DocFX](https://dotnet.github.io/docfx/) from the XML documentation
of the `RVZSharp` library. The public API is stable across the `1.x` line.
